# Tic Tac Toe Website

Static landing page for the game.

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with your real support email.
- Replace the contact section in `terms.html` and `privacy.html` with your real contact details.
- Make sure all descriptions accurately reflect your game.

## Render
Create a **Static Site**. Publish directory: `.`
No build command is required.
